# 资料理解与现金流计划

该模块用于理解合同或业务资料中的收付款条件，不把文字识别结果直接写成收入、成本、发票或实际收支。

首次识别可在明确模型授权后发送本次选择的PDF全部页面、图片或文档文字，以及最小项目／合同／主体名称。外部模型可能产生服务商费用；不发送其他账目，不偷偷截断资料，不增加反复重新识别按钮。未授权时保留本地查看与人工摘录。

模型输出必须包含来源位置、原文证据、收付方向、条件、比例与日期解释。系统复算金额和累计比例，输出绑定资料指纹和当前项目／合同版本；迟到或失效结果不能写回已关闭的表单。

用户先核对资料理解，再单独确认计划。相对日期、未发生条件或无法确定归属的内容保持待确认；计划不是到账记录，不覆盖正式财务事实。

专项使用合成资料及模拟模型，见 `tests/test_document_understanding.py`、`tests/test_document_cashflow.py`、`tests/test_document_cashflow_threads.py`。测试不会调用真实密钥或发送真实合同。
