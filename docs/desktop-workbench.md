# 本机网页桌面版

网页、原生桌面窗口与旧Tk界面共用Python服务、SQLite账本及附件。没有云端同步，不上传正式账本，不产生第二套利润或现金计算口径。

## 启动

先按README建立项目虚拟环境并安装 `requirements.txt`。原生窗口另安装 `requirements-desktop.txt`，Windows须有Microsoft Edge WebView2。

- `run_web_demo.bat`：创建全新合成演示账本，在浏览器体验录入；不要求正式数据库。
- `python web_workbench/desktop.py --demo qa/new-demo`：独立窗口演示。已有同名账本拒绝覆盖。
- `run_web.bat`：打开现有账本的只读浏览器界面。
- `run_desktop.vbs`：打开现有账本的只读独立窗口。
- `run_workbench.vbs`：打开现有账本的可录入独立窗口；启动前保存数据库与引用附件完整备份。
- `run.bat`：旧Tk兼容入口，不与新窗口同时录入同一账本。

初次正式使用时，按README显式创建空账本。已有账本必须先备份，检查迁移版本并在隔离副本演练；新入口不自动升级已有账本。

## 经营驾驶舱与明细

首页按“经营指标 → 走势与结构 → 应收跟进”组织。8张卡片点击展开明细；近6个月柱形点击查看对应月份。明细全量搜索、分页和合计独立，进入项目后可以返回原关键词与页码。

累计收入、回款、开票、应收与成本含已完工项目。毛利卡片明确只计算在营且可核算项目，不冒充净利润。项目回款按项目分配统计，独立历史旧账不混入工程收入，不开票现金工程不进入待开票余额。

## 附件与交互

合同、采购、发票、回款、成本与施工附件支持图片或PDF预览。PDF纵向连续阅读，屏幕附近页面按需渲染；关闭后释放预览资源，不发送外部服务。其他文档保留下载查看。

批量工天只列在职人员，0.5／1工及加班逐人选择；历史离职记录仍可查看。项目选择默认不列已完工项目，但既有记录编辑保持原关联。

切页和弹窗使用短暂透明度／位移动效，快速切换取消旧请求，支持减少动效与简洁实色界面。金额、日期、长中文和宽表以可读性优先。

## 安全与生命周期

- 只监听 `127.0.0.1` 的随机端口，校验Host、Origin与会话令牌，保留严格内容安全策略。
- 一个账本只能有一个交互录入端；重复启动同一窗口给保护提示。
- 窗口正常关闭后停止本机服务，释放端口和录入锁。不是已签名的独立安装包。
- 界面偏好保存在忽略的 `.local/desktop/`；原生桥只提供两个视觉开关，不提供任意文件访问或记账接口。
- 恢复前预检数据库、附件、范围和指纹，要求明确确认，并保存可回滚副本；状态不明时停止重复写入。
- 外部模型默认未授权；密钥、配置、账本和附件不进入Git。保存输入后正常关闭重开以加载更新，不强行中断未保存表单。

Python专项见 `tests/test_web_desktop.py`、`tests/test_web_workbench.py`、`tests/test_web_backup.py` 和 `tests/test_cockpit.py`。前端确定性检查见 `scripts/test_*.mjs`；实际窗口验收只使用新建合成账本。
