# 采购与材料报价计价口径

## 一单多材料（2026-09-12）

- 底部单独突出“当前材料金额（含税，不含运费）”，随当前材料计价实时更新；整单材料合计明确标注，加入本单或清空后当前金额显示“--”。

- 新增和修改共用材料编辑区与本单材料清单。供应商、日期、项目、付款状态及运费整单填写；“加入本单 / 继续填材料”仅暂存材料，最终保存整张采购单。
- 已加入材料支持选中修改、删除；最后一条尚未加入的有效材料也随整单保存。空白材料不落库，至少保留一条明细。
- 明细分别保留数量、过磅或总额计价及税价口径；整单运费只加一次。保存后可直接打开整单附件入口，附件不按材料重复上传。
- 列表按采购单显示，详情展开全部材料。整单修改保留明细编号与修改前后记录；失败整单回滚。旧单条调用不能覆盖多材料采购单。
- 导出逐行保留材料，运费只在首行显示；导入按采购单号合并并校验公共信息，同单任何错误均不保存该单。
- 验证：`tests/test_purchase_batches.py`、`scripts/accept_purchase_batches.py`；后者在隔离副本操作实际窗口和导入导出，不修改正式数据。

## 采购工作区布局（2026-09-09）

- 标签顺序为采购统计、全部采购、正式采购、零星采购、待归集；默认仍进入全部采购，统计指标不占据每个列表的顶部。
- 项目筛选按“项目名称 · 编号”显示；仅下拉列表按字体和内容加宽并避开屏幕边缘，筛选框不变宽。悬停显示完整选中名称，刷新时按项目 ID 保持选择。
- 主表显示日期、项目、材料及供应商、项目成本、真实支付状态、附件状态；单号与完整计价快照放在可滚动详情中。修改、附件、支付票据和作废操作固定在详情区，窄窗仍可触达。
- 宽窗口左右分栏，窄窗口上下分区；分隔条可拖动。表格保留横向滚动，长名称在详情区完整显示。
- 录入与修改共用自适应表单：足够宽时双列，窄窗单列，标签按实际 DPI 换行；日期控件保持紧凑。按数量、过磅与总额动态显示各自字段，多项目均摊保留全选和预览。
- 底部固定显示含税材料金额、另列运费和项目成本，保存按钮不随表单滚动。
- 界面验收：`scripts/accept_procurement_layout.py`；采购保存与导入导出：`scripts/accept_weight_purchase.py`。两者仅操作在线备份的隔离数据库。

- 报价表单和采购表单均可选择“含税价 / 未税价”，输入框标签同步显示当前口径，沿用现有主题和固定底部保存按钮。
- 新表单默认含税价；选择供应商材料时继承报价口径和原始报价。编辑采购时以历史采购快照为准，不能用当前材料报价覆盖成交价。
- 含税计价：含税单价乘数量确定含税材料总额，四舍五入到分；未税金额按总额除以税率因子，税额取差，项目成本另加运费。
- 未税计价：沿用未税单价乘数量、按未税金额计算税额；含税单位参考价标注“约”，不将显示四舍五入值反向作为总额计算依据。
- 服务层集中计算，金额输入按 Decimal 转整数分；修改保留前后记录，项目分摊保持金额守恒。
- Excel 导出保留“报价口径”，再导入时含税计价读取含税单价；无该列的旧格式继续采用历史规则。
- 验收：`tests/test_inclusive_purchase_prices.py` 与 `scripts/accept_inclusive_prices.py`，后者只操作在线备份的临时数据库。

## 采购计价方式

- 支持按数量、按过磅重量、按结算总额。字段渐进显示，含税／未税口径和运费对三种方式均有效。
- 按重量保存净重、吨／公斤、原始重量单价与磅单号。重量与单价必须使用相同单位；Decimal 保留原始精度，合计金额四舍五入到分，兼容单价字段只是显示快照，不参与反向重算。
- 按总额填写整批材料结算金额（不含另列运费），总额按所选税价口径拆分，内部数量为一批。转换模式后清除不再适用的重量／总额字段，保留采购修改历史。
- 过磅和整批采购可填写“混合规格钢材”等材料名称，不强制绑定单件报价；选择目录材料不会给重量单价自动套值。
- 采购列表显示计价方式、结算数量／重量、对应单价／整批金额与项目成本；保存后选中采购，通过“磅单 / 附件”上传磅单及规格清单。
- Excel 导出新增计价方式、实际净重、过磅单位、重量单价、整批结算金额、磅单号；旧模板仍按原逻辑导入。
- 迁移 500 不改变旧采购金额，默认保留按数量模式。验收见 `tests/test_purchase_settlement_modes.py`、`scripts/accept_weight_purchase.py`。

## 本机网页版

- 采购归集方式与材料类别独立：材料费（含耗材）、工具设备及其他采购均可选择“单项目归集 / 多项目均摊 / 待归集”。按整张采购单分摊，本单所有材料及运费只计算一次，不为分摊改写材料名称、类别、税价或付款事实。
- 选择均摊后显示项目勾选区，默认勾选目前未完工（筹备中／进行中）的项目，可取消或重新选中。已完工和已关闭项目不进入新均摊候选；编辑历史采购保留原归集项目并明确标注。至少选择两个项目，预览逐项目金额与合计，使用服务层整数分分配尾差。
- 均摊编辑回显已有份额，修改总额后按相同范围重算；保存后继续录入保留归集方式和所选项目，不重新选中全部项目。单项目切换为均摊时清除提交中的单项目归属，反向切换不带旧均摊份额。历史分摊版本保留，项目看板／成本明细只计本项目份额，公司采购总额不重复。

- 材料名称、规格等业务输入关闭浏览器“保存的信息”自动填充，不混入工人姓名或其他表单历史。供应商／项目／材料的关键词候选仍使用工作台的正式档案，不以浏览器历史代替。

- 新增材料报价选择供应商后，从当前供应商档案带入默认税率；预选供应商同样生效，明确传入的税率（含0%）和编辑历史报价的原税率保留。更换供应商重新带入新默认值，搜索未选定时清除旧自动税率；读取期间人工填写的税率不被迟到响应覆盖，关闭或换弹窗后丢弃旧响应。默认值允许本次修改，不反向修改供应商档案，不追溯改写已有报价。采购选报价仍优先沿用该报价的成交口径和税率。

- 采购主列表按“日期、材料名称／规格、项目、供应商、含税总额、付款、发票、单号”展示，不以内部单号作为主要识别信息。一单多材料在同一行逐项换行显示真实材料名称和规格；不截断、不只显示“多种材料”。名称及规格取成交快照，不套用最新报价；搜索任意一条材料或规格返回完整采购单，导出保留全部材料名称／规格。

- 采购材料报价严格按整单选定的供应商编号筛选，未选供应商不展示全库材料。供应商切换同步更新所有材料行，新增行与保存后继续录入沿用当前范围；失配报价关联清除，已输入的材料和成交价保留并提示核对。无报价的供应商允许直接填写材料。修改历史采购保留原报价和成交快照，不自动套用最新价格；迟到的旧报价查询不得覆盖切换后的供应商。
- 打开录入／修改以及新增材料行均使用本次最新读取的候选，不回退到启动时缓存。报价候选显示材料、规格、供应商、计价口径、单价／单位和报价编号；支持名称、规格、供应商组合关键词，以及 `*`、`×`、`x` 等尺寸分隔写法。
- 历史票据与付款状态原样呈现；“有发票／收据／无发票／未确认”和旧支付方式不能在编辑时静默变空。当前不在候选里的原记录须标明，仅用于保留历史关联，不加入新增采购／工天／成本的可选范围。
- 旧未税报价缺少独立原报价字段时读取其正式未税单价，不改写历史价格。修改采购材料必须保留明细编号 `item_id`，不能使用采购单 `id` 代替；浏览器提交的编号在服务边界校验并转成整数，避免错误归属或重复新增明细。
- 所有台账筛选后将页码限制在有效范围，不得因停留在旧分页而显示假空态。今日日期在每次新建时取北京时间当天，编辑保持原日期，跨天运行不能沿用启动日期。
- 项目、供应商与材料报价可关键词搜索并明确选择编号，键盘上下箭头与Enter可操作。采购列表优先展示关联供应商名称，零星商户仍取原快照。
- 当前材料显示含税小计和税额，整单显示材料合计、运费及总额；预览与保存共用原采购计算方法，不能用浏览器浮点反向计算金额。
- 按计价方式渐进显示必要输入；日期宽度只需容纳完整日期和日历按钮。弹窗内容独立滚动，底部保存／取消固定可见。
- 新采购可勾选保存后继续录入，保留项目、供应商、日期和付款票据条件；新材料、运费、金额和确认勾选重新填写。没有勾选时保存后退出。
- 附件窗口共用本机预览：图片可适应窗口与缩放，PDF各页纵向连续排列，鼠标滚轮／触屏上下滚动阅读，不需逐页点按钮。顶部保留当前页码与缩放，默认适应宽度；按真实页面尺寸预留位置，横版／旋转页不引起布局跳动。附近页面串行加载，最多保留6页图像，离开阅读范围和关闭预览时释放。预览使用独立弹窗，不替换附件表单、不清空已选文件和说明，也不修改正式业务记录。下载入口保留，其他格式明确提示暂不支持预览；移出附件须从历史列表显式查看。
