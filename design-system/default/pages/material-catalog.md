# 材料与报价

- 材料目录和供应商报价同页展示，但产品名称、规格、单位、供应商须可单独识别。
- 报价录入明确含税或未税口径；税率及换算价成对展示，不要求用户反凑单价。
- 供应商报价历史不等于实际采购单价，页面不能把报价覆盖成采购事实。
- 查询、选中、修改与清空表单的状态应清楚；批量删除前显示影响数量。
- 长产品名、规格和供应商名优先保留可读宽度；金额右对齐。
- 本机网页将“材料报价 / 报价对比”作为同一工作区的两个页签；原比价链接保留兼容，不再设同级导航。
- 从供应商进入报价时按档案编号限定范围并显示当前供应商；返回恢复筛选和位置。比价仍使用统一报价目录，不复制材料及报价记录。
