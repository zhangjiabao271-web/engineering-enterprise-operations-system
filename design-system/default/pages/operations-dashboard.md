# 经营驾驶舱页面规范

前半部分保留旧 Tkinter 页面的规范；当前网页桌面版以“本机网页桌面版”一节为准。

## 页面目的

让经营者在一分钟内判断：有多少在营项目已经能可靠核算，哪些项目仍缺合同、成本、结算、开票或回款事实。

## 信息顺序

1. 项目经营可核算率，并显示“可核算项目数 / 在营项目数”。
2. 已确认项目毛利、应收未收、未归集成本。
3. 全部项目经营闭环表。
4. 合同分配、采购归集、人工归集、结算确认组成的经营闭环索引。
5. 可直接进入对应业务台账的今日优先处理事项。
6. 施工产值不等于收入、利润不等于现金的口径提醒。

## 项目闭环表

固定列为：

- 项目
- 当前阶段
- 结算确认
- 已归集成本
- 确认毛利
- 现金余额
- 当前数据缺口

没有结算确认的项目，毛利显示“待结算”，不得显示一个貌似精确但不可解释的负数。澄湖、蓝湾等项目始终独立成行。

## 视觉与交互

- 采用中性表格行和普通文字阶段，不使用高饱和状态块。
- 采用全局浅灰侧栏、白色工作区与圆角控件，信息层次用留白和字重表达。
- KPI 使用中性浅灰圆角卡片与清晰大号金额，不添加右上角装饰动效。
- KPI 不使用“项、利、收、本”等伪图标或方形文字占位符。
- 闭环索引只展示真实覆盖率，采用蓝色细线串联。
- 项目表占页面主要宽度，右侧经营待办固定为约 270px，避免挤压项目表。
- 右侧窄栏只保留可处理待办，不重复展示闭环索引中已有的覆盖率。
- 双击项目行进入项目经营核算。
- 1200×800 下四个指标保持单行，项目表自身滚动。
- 刷新只重新读取经营视图，不改变业务数据。

## 正式口径

在营项目同时存在有效合同项目分配和有效结算确认时，进入“可核算”状态。合同、结算、发票、回款和成本必须来自各自正式事实模块。

## 本机网页桌面版

- 首页优先显示“今日自检”和“今日经营关注”。自检固定核对当日工天及采购，展示按业务日期统计的工人数／采购单数；不把零记录判成漏录，也不把一条记录判成全部录完。
- 自检由用户选择已录完、今日无业务、稍后处理或撤销。完成收起但不删除，跨日生成独立新清单，以前未核对事项带原日期保留；确认后源记录变化自动重新待核对。
- 从历史自检进入新增工天或采购时沿用该项原日期，不默认改为今天；保存仍使用原业务入口的确认流程。
- 自检是全公司录入核对，项目筛选只作用于经营关注，并明确两种范围。只读入口可以查看但不能确认或忽略。
- 经营关注优先展示到期催款、完工未收款、未归集成本和真实附件缺失，默认最多3项，其余按需展开。无约定到期日不称为付款逾期。
- 去处理沿用原业务入口；催款内容仅为待人工核对的沟通草稿，不发送、不虚构客户承诺。提醒可暂缓或忽略，源依据变化后重新出现；补齐源业务后不再触发，保留处理历史。
- 本地检查不调用外部模型；页面重入、用户操作及可见首页的定期复查刷新，切页或隐藏时不干扰录入。提醒状态不更改收入、成本、发票、回款或实际资金。

- 2026-10-11：改为“经营卡片 → 走势与结构 → 应收跟进”的总览；首页不常驻完整长表，在营项目表折叠展示。
- 两组各四张可点击卡片：确认收入、项目回款、应收未收、销项开票；已归集成本、在营可核算项目毛利、待开票、待归集成本。每张标明真实口径，点击读取新的只读快照、明细合计与可搜索记录，不出现保存按钮。
- 累计收入、开票、回款、应收与成本包括已完工项目。毛利保持既有“在营可核算项目”范围；独立历史旧账不混入工程回款，不将采购付款差额称为银行现金余额。
- 顶部项目范围同时筛选所有卡片、走势、结构和明细；单项目范围不显示其他项目或全公司待归集费用。
- 展示连续六个月确认收入/项目回款/成本走势；各自按实际记录日期统计，末月不假设为完整月份；柱形可点击到对应月份明细。
- 成本结构分采购、人工与费用；客户应收分布按客户ID汇总，项目保持独立、不跨项目抵扣。应收列表包含已完工仍未收款的项目。
- 卡片采用原生按钮，支持键盘和清晰焦点；窄屏使用两列，金额和名称不裁切。只在点击时加载逐笔明细，关闭/切页后迟到响应不重开旧弹窗。
- 明细支持全量搜索及筛选小计，每页最多100条，分页不截断总额；进入项目台账或项目成本后，可返回驾驶舱明细并保留关键词和页码。
- 首页提供“逐笔回款记录”直达入口，打开回款页签而非发票或汇总；实际到账与项目分配保持独立口径。
- 沿用统一服务的 `is_accountable` 判定；顶部毛利卡仅汇总在营可核算项目。在营项目表显示全部账面毛利及核算状态，待完善项目保留收入、成本与差额，并明确不代表已确认盈利；不改写底层金额。
- 每个项目直接打开合同与结算或全周期成本明细。表头和操作列固定，宽表内部横滚，项目表独立纵向滚动。
- 采用全局克制玻璃导航与轻切页动效；数据卡片和账目表保持实体底色。
