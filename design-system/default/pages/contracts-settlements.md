# 合同与结算页面规范

## 合同计价

- 年度框架合同新增时默认“单价据实结算”，但历史合同继续保持“固定总价”。
- 固定总价显示“含税合同金额”，并继续作为项目分配和收入确认的硬边界。
- 暂定总价显示“暂定金额”；超过时明确提示，但不阻止收入确认。
- 单价据实结算不显示合同金额，说明口径为“实际工程量 × 协议单价”。
- 暂定总价和据实结算可填写独立控制上限；控制上限只预警，不改写合同金额。

## 渐进表单

- 据实年度合同可选择“随回款补足实际结算”：超过本项目、本合同既有确认的回款同步新增结算；以后开票仅关联已有结算。启用时明确告知回款同时证明结算，历史预收和待分配回款须先核对。
- 已确认结算独立保留，修改或作废回款不会自动减少收入；结算更正仍通过收入确认入口并受已有发票、回款余额约束。

- “计价方式”控制金额字段：无关字段必须隐藏，不留空白占位。
- 所有金额字段保留可见标签，错误在当前弹窗内反馈并保留已输入内容。
- 日期继续使用日历选择器，保存和取消固定在弹窗底部。

## 台账表达

- 顶部支持项目筛选。由项目经营核算跳入时预选该项目，并同时筛选合同、项目分配和收入确认；合同约定金额仍是整份合同口径，不误称为该项目金额。
- 合同台账依次展示计价方式、约定金额、控制上限、累计确认和涉及项目数。
- 据实结算的约定金额显示“据实结算”，不显示为零元合同。
- 项目数按项目分配与收入确认项目的并集统计。
- 累计确认超过暂定金额或控制上限时标记“超额”，合同原值不得随累计确认变化。

## 合同与项目关系

- 固定总价和暂定总价合同使用正金额项目分配；单价据实合同使用零金额项目关联，台账显示“据实关联”而不是“0元分配”。
- 收入确认的“合同与项目”只能来自当前有效的真实关联/分配，不得临时组合任意合同和正式项目。
- 正式合同收入保存时由服务层再次校验关系；据实和暂定合同要求已关联，固定总价还要校验累计收入不超过项目分配额。
- 合同与项目客户不一致时禁止建立关系，避免收入和成本串到其他客户。
- 历史固定总价或暂定总价合同允许修正为单价据实结算：保存前提示影响，并在同一事务内把有效金额分配改为零金额据实关联；收入确认、发票和回款归属保持不变。
- 已有项目关系或收入确认的据实合同，不允许直接反向改为固定总价或暂定总价，避免凭空产生合同金额和分配边界。

## 零星现金工程边界

- 已设置约定总额的现金项目，收入确认弹窗显示约定总额、除本笔外已确认金额和本笔最多可确认金额。
- 达到约定总额后，确认金额输入进入不可用状态；服务层仍必须在新增和修改时再次校验，界面状态不能代替业务规则。
- 未设置约定总额的现金项目继续允许多笔完工确认，界面明确提示“未设总额”，不把它误显示为零元项目。
