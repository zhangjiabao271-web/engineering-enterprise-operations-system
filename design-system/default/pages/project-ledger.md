# 项目台账

- 每行展示项目／客户／施工状态，以及合同约定额、已确认收入、实际回款、已开票、未回款、累计成本、项目毛利。完整中文和金额保留可读列宽，宽表只在表内横滚并复用悬浮横向条与表头。
- 合同约定额按本项目的有效合同分配统计；全为据实合同显示“按实际结算”。合同明细同时展示整份合同和本项目份额，不混为同一口径。
- 账面毛利＝已确认收入－项目累计成本；采购、人工和费用复用正式成本来源。点击金额查看全周期明细，成本可继续进入原来源明细，毛利显示加减计算依据。
- 项目行明确显示待补合同业务的笔数与金额、预收／待分配回款。点击提醒进入相应明细；未签业务可从原行补关联合同。
- 由金额明细可直接登记本项目的合同、确认业务、回款或发票，默认沿用项目范围。返回上一级保持既有导航语义，不新增重复项目工作空间。

## 本机网页视图收拢（2026-10-18）

- 一级入口“项目台账”内包含“经营台账 / 核算分析”。核算视图不再占用侧栏，原 `#profit` 链接兼容跳入核算页签。
- 两视图及驾驶舱共用有效收入、有效合同分配的核算状态。待完善项目仍显示真实成本及账面差额，不因缺资料从成本合计剔除。
- 已确认毛利只汇总“已可核算”项目，待完善项目账面差额单独解释；不能将包含待完善项目的总差额标成“已确认毛利”。
- 客户概览进入项目台账时按客户档案编号过滤；切换核算视图继续保留客户与项目范围。金额明细复用原项目台账，不另造写入链。
