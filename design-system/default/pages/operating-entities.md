# 经营主体

## 默认视图

- 示例钢构与示例安装并排比较；主体名称、一般／小规模纳税人身份完整显示，不裁字。
- 顶部显示全部项目确认收入、项目回款、应收未收及待处理归属数量。主体卡片展示名下项目收入、回款、成本、账面毛利、待收款和主体销项票；数字均可展开对应记录。
- 项目经营数据按明确的合同／无合同项目归属统计。票据主体是独立事实：销项与进项按实际票据归属统计，不用项目归属覆盖已确认的票面主体。
- 未归属金额单列；已知主体合计加待归属必须等于全量事实。未知不得默认为示例钢构、示例安装或零金额。
- 成本按项目分摊份额统计，不能把一张均摊单完整重复计入两家主体。账面毛利使用已登记含税成本，不称为净利润或现金余额。
- 一张采购／费用合理分摊到不同主体的项目时，项目成本已分别计入；原始单据显示“多主体项目分摊／实际购买主体待确认”，不是合同归属冲突。关联进项票必须先明确原始单据购买主体。
- 主体进项票属于整张票据，不把多项目票据完整算给选中的某一个项目；项目范围下提示切回全公司查看。

## 合同优先归属

- 合同是有合同项目的归属入口。合同主体确认后，有效关联／分配以及有效业务事实关联的项目立即动态沿用，无需再确认一次项目。
- 有合同项目不可通过“项目归属”改出与合同不同的主体；界面提供“查看关联合同”并在合同处确认／更正。
- 无有效合同时，零星现金工程、无合同项目可独立确认主体。保留旧人工确认和审计历史，不物理删除。
- 多份关联合同属于不同主体时显式显示归属冲突；仍有未确认合同则不假定都属于已知主体。
- 合同未确认且项目已有历史人工确认时保持可见，不擅自删除旧确认。明确合同归属以后合同优先，界面说明来源。
- 补充协议无独立确认时沿用原合同主体；循环关系、作废合同不形成自动归属。
- 已单独确认的发票、回款、进项票和资金主体不被合同确认覆盖。更正需独立业务依据。

## 归属台账与操作

- 合同／无合同项目主体变更必须校验关联单据的继承影响，不能绕过有效资金流水或进项票主体保护；预览提前提示，批量确认任一项失败时全部回滚。
- 原始单据独立确认优先；未变动的历史归属不阻止无关资料更正。已作废证据不作为当前阻拦依据，历史仍保留。

- 台账按类型、归属状态和关键词筛选。每条记录明确显示“已确认／已自动归属／待确认／归属冲突”、主体名称、来源及原因。
- 默认合同待处理队列，支持复选框、全选当前筛选、取消选择、批量确认。无需 Ctrl 多选。
- 确认前预览旧／新主体和关联项目影响；确认控件不预选。取消、预览、查看历史均不修改正式记录。
- 保存成功重新读取看板、状态计数和当前队列。已处理记录从待处理队列消失，可在“全部记录／已人工确认”核查；重复相同确认明确提示无变化。
- 读取类型切换时清除旧候选并禁用确认；迟到读取不能覆盖新类型。保存中冻结关闭、取消及重复提交。
- 依据与历史、数字明细可只读查看；只读入口不能勾选或确认。

## 验证

- 合成账本验证合同联动、零星项目、冲突、分摊尾差、明细对账、取消及只读保护。
- 实际浏览器检查确认前后状态、数字卡片明细、切页重入和 1366×768／手机宽度布局。宽表在表内容器滚动，主体名和说明完整换行。
