# Construction Management Page Override

- Treat each project as an independent large location, such as `澄湖` or `蓝湾`.
- A construction record belongs to exactly one project; never mix records across projects.
- `具体作业位置` is a free-entry field within the selected project, with prior values offered as suggestions.
- One record represents all installation work at one internal location over an inclusive start/end date range.
- Capture materials, specifications, lengths, quantities and other installation notes in one large multiline free-entry field.
- Do not force one material, specification or quantity into one database record.
- Put the engineering amount after the multiline installation details.
- Engineering amount is an operational recorded amount, not cash receipt or accounting revenue.
- Keep save/cancel actions fixed in the dialog footer and allow vertical mouse-wheel scrolling.
- Use one filled primary action per page; keep edit, acceptance and photo actions neutral.
- Show acceptance state as text without tinting the entire table row.
- List columns prioritize project, period, internal location, installation-details preview, amount and status.
