# 数据导入导出与归档

- 供应商、材料报价、采购记录的导入和导出按业务对象分组，导入需说明模板与结果。
- 导入结果分别给出成功和失败条数；失败行不得悄悄丢弃，已成功行不得误导重复导入。
- 项目经营全量工作簿是报表导出，不替代数据库和附件的备份。
- 恢复备份须明确覆盖范围、附件风险和隔离预检；页面上将其与普通导出区分。
- 大量数据处理期间给进度或完成反馈，确认后才能执行不可逆覆盖。

## 本机网页备份与恢复

- 完整 ZIP 独立于 CSV / Excel 报表。打包有效及历史附件、施工照片、进项票与资料来源，列明版本、工程/历史回款记录数、已打包和缺失文件数；缺失不能显示成“完整无缺口”。
- ZIP 上限512MB，分片4MB，上传提供进度；重复分片必须内容一致。预览/确认令牌30分钟有效，取消只丢弃暂存，不覆盖账本。
- 恢复核对版本、文件哈希、目标目录、数据库完整性及外键；隔离副本不得重新关联正式附件。预览后资料或账本变化则拒绝旧确认。
- 覆盖确认不能预选，用户必须输入“恢复该账本”。恢复前保全原库和原文件；失败状态不明确时界面转为只读并保留安全材料，不鼓励重复点击。
- 恢复成功重新读取页面，清除旧表单预览和助手任务，换新会话令牌；原生下载必须经过实际另存为验收。
