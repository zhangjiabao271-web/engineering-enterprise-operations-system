# 工程企业经营系统设计系统

更新日期：2026-09-25

适用范围：Python + ttkbootstrap 桌面端

本文件用于跨页面设计；局部修改只读取相关页面规范与 `ui/theme.py`。样式数值以主题实现为准，下述规范提供设计意图，不要求每次重建设计系统。验证范围见根目录 `WORKFLOW.md`。

## 1. 设计目标

界面首先帮助经营者快速回答三类问题：

1. 哪个项目赚钱、哪个项目现金吃紧。
2. 当前数字是否可信，还缺哪些业务事实。
3. 下一步应该补合同、归集成本、办结算、开票还是催款。

不以“科技感”或装饰性为目标。信息层级、可追溯口径和连续录入效率优先。

## 2. 视觉基线

- 中文界面：`Microsoft YaHei UI`。
- 页面标题 22pt、粗体；分区标题 11pt；正文 10pt；辅助文字 8pt。
- 使用 4/8px 间距节奏；页面边距 24px；表格行高 38px，按显示缩放比例适配。
- 采用接近 macOS 桌面工具的浅色层次：侧栏 `#F2F2F5`，白色工作区，中性浅灰指标卡 `#F5F5F7`。
- 正文 `#1D1D1F`，辅助文字 `#63636B`，边框 `#DEDEE5`，操作强调色 `#0066CC`。
- 金额和百分比使用 `Segoe UI Semibold`，中文标题与正文使用 `Microsoft YaHei UI`。
- 侧栏基准宽度 224px，统一线性图标和蓝色圆角选中态；内容超出时可滚动。
- 控件使用统一圆角，页面保持平静的白色表面；避免层层描边与装饰性背景动画。
- 指标卡可使用中性浅灰底，信息区采用细边框与留白分组，状态仍以可读文字为主。
- 主操作为蓝底白字圆角按钮；辅助操作使用白底细描边或文字按钮。
- 键盘焦点、悬停、按下和禁用状态必须可辨认，控件反馈不改变布局尺寸。
- 状态优先使用普通文字。必须使用颜色时，颜色只作辅助，旁边保留明确状态文案。

## 3. 信息密度

- 一个页面只保留一个主任务区，次级指标放在右侧或下方。
- 顶部核心指标最多四个，并同时给出口径或分母。
- 表格是经营页面的主要表达方式；没有明确决策用途时不增加图表。
- 金额默认右对齐，状态居中，名称和问题说明左对齐。
- 空数据必须说明“尚未录入”或“当前为 0”，不得制造看似完整的默认结果。
- 澄湖、城北等独立项目必须分行显示，不因客户或年度合同相同而合并。

## 4. 操作规范

- 主操作使用蓝底白字；同级辅助操作使用中性描边或文字按钮。
- 业务操作和导航使用明确文字；日历等已有标准控件可沿用图标，但须保留字段标签和可理解的操作含义。
- 已发生业务的记录使用作废、红冲或调整，不使用物理删除。
- 批量操作前展示数量和影响范围。
- 表单错误就近提示，并保留用户已输入内容。
- 复杂表单采用渐进显示：当前选择不需要的字段、预览和辅助操作不得占据页面空间。
- 键盘焦点必须可见，Tab 顺序符合阅读顺序，Escape 可关闭弹窗。
- 侧栏切页先完成真实控件布局，再使用仅存于内存的旧页快照进行约 160ms 淡出，采用快速响应、自然减速的三次缓动；按实际时间推进，迟到帧直接跳过，不逐帧移动整页控件。连续切页、窗口移动或缩放时取消旧过渡并释放快照。
- 驾驶舱、供应商、采购、开票回款和人工工天五个常用页复用界面控件，保留筛选条件，但每次重入必须重新读取正式数据和更新选项；驾驶舱刷新统计月份，项目深链接继续定位指定项目。其他页及 AI 后台任务不缓存，隐藏页不执行持续动画。
- 圆角大面积表面使用较大的九宫格底图中心，减少 Tk 重复铺图的绘制开销；显式保持原控件最小尺寸，不通过扩大控件解决性能问题。
- 快照仅截取本应用内容窗口，不截取桌面或其他应用，不保存文件。截图不可用或界面持续繁忙时直接切页；动效验收同时检查实际回调帧间隔，不能只检查动画最终完成。
- 遵循 Windows 的减少动态效果设置，侧栏提供本次运行的动效开关；用户开关不能覆盖系统减少动效设置，运行中关闭立即结束过渡。弹窗在表单构建完成后的首个回调开始约 160ms 轻淡入，关闭时取消回调；不持续播放与操作无关的图形。

## 5. 弹窗规范

- 所有编辑弹窗默认可缩放。
- 内容超出可用高度的表单支持鼠标滚轮和触控板滚动；短表单无需机械加入滚动容器。
- 保存、取消等操作固定在底部，不随内容滚出可视区。
- 初始尺寸必须在 1366×768 屏幕内完整显示，最小尺寸仍能触达操作按钮。
- 主窗口与弹窗必须使用 Windows 实际工作区尺寸，避开任务栏和系统停靠区域。
- 长文本使用大文本框，不把多材料、多规格、多长度强行压入单行字段。
- 本机网页异步打开表单、附件及批量工天时，以最新点击和当前页面为准；关闭或切页后迟到的响应不得覆盖新表单，旧表单票据尽力丢弃。保存阶段不作为可取消读取：保存中锁定关闭和重复提交，等待明确结果。

## 6. 数据表达规范

- 金额统一显示两位小数；底层使用整数分。
- 负数显示为 `-¥1,234.56`，不使用颜色作为唯一提示。
- 百分比显示一位小数，同时给出分子和分母。
- 施工记录金额、已验收金额、结算收入、开票和回款必须分别呈现。
- 毛利与现金余额必须分别呈现。
- 未归集或来源不明的数据必须进入可见待处理队列，不强行匹配。

## 7. 页面骨架

```text
页面标题 + 一句话任务说明                         口径/状态
主操作  次级操作                                      刷新
核心指标 1 | 核心指标 2 | 核心指标 3 | 核心指标 4
主任务表 / 主表单                            驱动指标 / 风险
```

具体页面存在 `design-system/default/pages/*.md` 时，以页面规范为准。

## 8. 交付检查

仅检查本次涉及的页面和交互；完整桌面验收时再覆盖所有受影响窗口。

- 经营数字是否同时展示口径和数据缺口。
- 是否错误合并了独立项目。
- 是否把产值当收入、把利润当现金。
- 主要内容在 1200×800 下无需放大窗口即可完成操作。
- 弹窗可缩放、可滚动、操作按钮固定。
- 文本对比度达到 4.5:1，焦点可见。
- 没有装饰性高饱和色块、方形标签或无用途图表。

## 9. 本机网页桌面版补充（2026-10-05）

本节仅适用于 `web_workbench/` 的浏览器和 WebView2 窗口，不替换上述 Tk 字体、快照或控件规则。

- 浅色工作区使用统一线性图标。玻璃限于导航与顶部工具栏，账目、表单和助手正文保持实体底色；提供可持久化的实色界面。
- 导航胶囊约 180ms、切页 170ms、弹窗进入 180ms/取消退出 100ms，只动画 transform/opacity。快速操作取消旧动画；键盘即时反馈，隐藏页停止动画。
- 切页动效使用每次新建的内容层，不复用带动画的主容器；移动原有节点保留事件绑定，开始新页面前取消旧内容层动效。验收包含真实鼠标命中及切页往返，不以代码触发 `.click()` 代替可点击性检查。
- 系统减少动效优先于用户设置，不能反向开启；视觉偏好与经营账本分离。
- 表头纵向固定，操作列随宽表内部横滚，不固定在数据列上方；正文完整显示、长中文自然换行，金额保持单行。小屏窗口按实际工作区缩小，关闭和表单操作保持可访问。
- 长表的原横向滚动条尚未进入视野时，在当前可视区域底部提供同步悬浮条；原滚动条可见、表格离开视野、无横向溢出或弹窗打开时收起。拖动、键盘与表内滚动保持同一位置，不影响账目。
- 顶部提供“返回上一级”，返回实际进入当前页的页面；恢复项目范围、页签、查询、分页、页面及表格滚动位置。直接打开子页时可返回经营驾驶舱，不跳到应用外的浏览历史。
- 弹窗关联查询按表单会话与最新选择检查代次；切项目立即清除并暂时禁用旧候选，未完成或失败的查询不得静默跳过保存。已关闭表单的结果不能修改新表单，移除材料行同时取消其待处理状态。
- 保存或预览处理中冻结表单内容、关闭和取消，拦截Escape与重复提交；下一步预览完成后恢复操作。保存失败保留输入并解除锁定，不把旧提交的错误显示到新表单。
- 浏览器与只读入口保持正式账本只读；主录入入口显式授权写入并先完整备份，旧版和新版可写入口共用账本录入保护。正式启用状态以桌面交付文档为准。独立窗口首开最大化、可还原，自行管理本机后台启停；动效采样须说明设备、数据与浏览器，不将一次采样外推为恒定帧率。
